## Управление сайтом

Панель: https://dreamshrouded.github.io/denis-suvorov-portfolio/admin.html

- Редактирование 75 полей: первый экран, результаты, опыт по компаниям, экспертиза, контакты и образование.
- Предпросмотр показывает черновик, не меняя публичный сайт.
- Кнопка «Управление сайтом» удалена из футера. В шапке она появляется только при открытой панели с подтверждённым через GitHub API аккаунтом владельца (постоянный GitHub ID 88829985). После подключения нажмите «Открыть сайт» в панели. При отключении, закрытии панели или потере подтверждения кнопка исчезает.
- Состояние присутствия передаётся только между вкладками одного сайта в одном браузере через BroadcastChannel. Ключ в канал не передаётся и не записывается в браузерное хранилище. Проверка аккаунта обновляется каждые 30 секунд при запросах; без ответа кнопка скрывается через 25 секунд. Отзыв ключа отражается после следующей проверки GitHub; время зависит от сети и активности вкладок. Если BroadcastChannel недоступен, кнопка остаётся скрытой; панель работает по прямой ссылке.
- Это управление видимостью ссылки, а не закрытый серверный раздел: статическая страница admin.html остаётся публичной. Право записи проверяет GitHub.
- Для публикации подключите fine-grained personal access token GitHub: только этот репозиторий, разрешение `Contents: Read and write`, ограниченный срок действия. Создание и ввод ключа выполняет владелец. Ключ отправляется только в GitHub API, хранится только в памяти вкладки и удаляется при отключении/перезагрузке. Он не сохраняется в localStorage, исходниках, черновике или истории публикаций.
- Перед записью проверяется версия content.json. Если она изменилась, панель остановит публикацию. GitHub дополнительно проверяет права и SHA файла.
- Публикация сохраняет content.json в main. После успешной сборки GitHub Pages содержимое увидят посетители. История версий остаётся в GitHub.
- Черновик хранится только в текущей вкладке. Перед закрытием при наличии изменений появляется предупреждение.
- Изображения и структуру разделов по-прежнему меняют через репозиторий. HTML сохраняет исходные тексты как запасной вариант на случай недоступности content.json или JavaScript.

## Работоспособность

`.github/workflows/site-health.yml` выполняется на GitHub Actions в 17-ю и 47-ю минуту часа, после успешной публикации Pages и вручную через Run workflow. Проверяет HTTPS-ответ главной страницы, обязательные разделы и контакты, формат редактируемого содержимого, наличие панели, сценариев, стилей, иконки и трёх изображений. При временном сетевом сбое делает до трёх попыток. При ошибке завершается с неуспешным статусом; таблица результатов доступна в сводке запуска.

Панель получает историю реальных запусков, отдельно показывает проверку из текущего браузера, ошибки получения статуса и отсутствие свежей завершённой проверки более 90 минут. Проверка не оценивает внешний вид и доставку через внешние каналы связи. Уведомления об ошибках зависят от личных настроек GitHub Actions. Расписание GitHub может задерживаться и отключается после 60 дней отсутствия активности в публичном репозитории.

Документация: [обновление файлов через GitHub API](https://docs.github.com/en/rest/repos/contents#create-or-update-file-contents), [расписание GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).
