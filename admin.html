Что именно отслеживается

Ответ страницы, обязательные разделы, файл содержимого, стили, сценарии и изображения. Ошибка отмечается в GitHub Actions; уведомления приходят согласно вашим настройкам GitHub. Проверки не оценивают внешний вид и не подтверждают доставку сообщений через почту или Telegram.

Если свежего результата нет более 90 минут, панель покажет, что мониторинг требует внимания. GitHub может задерживать запуск; в неактивных публичных репозиториях расписание отключается через 60 дней.

ДОСТУП ВЛАДЕЛЬЦА

Подключить GitHub

Для публикации нужен ключ доступа только к репозиторию dreamshrouded/denis-suvorov-portfolio с разрешением Contents: Read and write.

Подключение проверяется для аккаунта владельца dreamshrouded. После входа нажмите «Открыть сайт» и оставьте эту панель открытой — кнопка управления будет видна в шапке только в вашем браузере.

Создайте fine-grained token в GitHub, выберите этот репозиторий и короткий срок действия. Панель отправляет ключ только в GitHub API и хранит его в памяти вкладки до отключения или перезагрузки.
